# World Coffee Research(WCR) 調査まとめ

2012年設立の非営利農業研究機関。世界のコーヒー業界(200社以上の会員企業)が
共同で資金を出し、品種改良・気候変動対応などの農業科学研究を推進している。

---

## 1. サイト全体像と、このアプリとの関連度

WCRのリソースライブラリは50件以上あるが、大半は**気候変動対策・遺伝学・
種苗事業支援・栽培技術**といった農業R&D領域の専門資料で、産地・精選方法・
グレード・焙煎度・テイスティングノートを扱うこのアプリの対象範囲(店頭で
消費者が触れる情報)とは異なる。以下の2点が直接的に関連する。

## 2. Sensory Lexicon(センサリーレキシコン)

- **カンザス州立大学の感覚分析センターで作成**された、コーヒーの風味・香り・
  質感を測定するための世界最大級の共同研究プロジェクト
- **これがSCAコーヒーテイスターズフレーバーホイールの基になった研究**である
  ことが公式に確認できた(以前の調査での推測が裏付けられた)
- 110種類の風味・香り・質感の属性を特定し、それぞれの強度を測定するための
  基準サンプルを提供
- 2017年に「Lexicon 2.0」として、24属性(Sour, Bitter, Salty, Apple, Grape,
  Coconut, Pineapple, Acetic acid, Butyric acid, Isovaleric acid, Fermented,
  Peapod, Fresh, Papery, Musty/Earthy, Musty/Dusty, Moldy/Damp, Phenolic,
  Petroleum, Brown Spice, Almond, Vanillin, Floral, Jasmine)の新しい基準
  参照サンプルを追加。前回SCAフレーバーホイールPDFから抽出した用語と一致

## 3. Coffee Varieties Catalog(品種カタログ)

- **55種のアラビカ品種・47種のロブスタ品種**を網羅した、初めての統一的な
  品種カタログ(農学データ:収量・栄養要求量・最適標高・病害虫耐性等を含む)
- コーヒーの木の寿命は20〜30年に及ぶため、品種選定の判断ミスは生産者に
  長期的な損失をもたらす、という課題意識から作られた
- 主要な品種系統:
  - **ティピカ系統**: Typica, Pache, Kent, Java
  - **ブルボン系統**: Bourbon, SL28, SL34, Pacas, Villa Sarchi
  - **カトゥーラ/カトゥアイ系統**: Caturra, Catuai, Mundo Novo, Maragogype, Pacamara
  - **サルチモール/カティモール系統**(コーヒーサビ病耐性の交配品種): Catimor,
    Sarchimor, Ruiru 11, Batian, Parainema
  - **特殊・高付加価値品種**: Geisha(ゲイシャ)、Starmaya・Marsellesa(F1ハイブリッド)
- ロブスタは西アフリカのサハラ以南の森林が原産。1870年頃コンゴで商業栽培が
  始まり、1950年頃からブラジル・ベトナムを中心に急拡大した

## 4. データモデル・パーサーへの反映

- 商品名・説明文で言及されやすい主要品種を`VARIETY_KEYWORDS`としてコードに
  追加(ティピカ/ブルボン/カトゥーラ/カトゥアイ/ゲイシャ等)。これまで
  `PRODUCER_LOT.variety`は表組みから取得できた場合のみ埋まっていたが、
  商品名・説明文からのキーワード検出でも品種を拾えるようになる
- PHILOCOFFEAの「Heirloom」(エチオピア在来種)、MiLL Coffeeの「ゲイシャ」は
  いずれもこのカタログに含まれる実在の品種であることを確認

## 5. 留意点

- WCRの品種カタログは膨大な系統(交配品種・地域限定品種等100種以上)を含み、
  今回はその中でも消費者向け商品説明に登場しやすい主要品種のみを抜粋した。
  マイナーな交配品種(例:BRS 2299、INIFAP 97-14等、育種番号がそのまま
  品種名になっているもの)は今回のマスタには含めていない
- WCRの他のリソース(気候変動対策、遺伝学研究、種苗事業支援等)は今回
  対象外とした。必要であれば個別に深掘りできる
