# B区分 出典整備 バッチ4(タンザニア・イエメン・ベトナム、最終バッチ)

`ORIGIN_GUIDE`棚卸し監査でB区分に分類された9カ国の最後の3カ国。これで17カ国全ての
A区分・B区分整理が完了する見込み。

依頼時の指示により、以下の既存出典は変更せず維持する:
- タンザニア`harvestSeason`(本文中のUSDA GAIN引用のまま)
- イエメン`varietiesDetail`(Qima社DNA解析への言及のまま)
- ベトナム`varietiesDetail`(sources+本文中のUSDA FAS引用のまま)

上記以外の見出しを、既存5カ国等と同じ形式(全見出し対象の包括的な`sources`)に
引き上げる。タンザニアは`officialBody`、イエメンも`officialBody`が
[coffee-discovery-facts-sources-9countries.md](coffee-discovery-facts-sources-9countries.md)
で個別に出典済み(いずれも6見出しの対象外)。

出典は専門商社(**Sweet Maria's**・**Royal Coffee**・**Genuine Origin**・**Perfect Daily
Grind**)に加え、イエメンは専門輸出業者**Qima Coffee**関連の報道記事も参照した。

## タンザニア

### テロワール
アラビカは北部(キリマンジャロ・アルーシャ・メルー山麓)と南部高地(Mbeya・Ruvuma・
Songwe等)で栽培。北部はキリマンジャロの火山性土壌でバナナ等との混作が多く、
甘くバランスが良くほのかな酸を持つ(バニラ・チョコ・プラリネ様の風味)。南部高地
(標高1,250〜1,400m、火山性土壌)は近年生産の中心で、国内生産の75〜85%を占めるまでに
拡大しており、黒チェリー・タンジェリン系の果実味とチョコレート・モラセス・
キャラメルの風味、絹のようなボディが特徴とされる(Perfect Daily Grind)。

### 栽培品種
主力はブルボン系統とケント、TaCRIが開発したブルボン系選抜のN39。ケニア由来の
SL28/SL34、K7、耐病性のRuiru-11/Batianも導入されている(Royal Coffee)。

### 農園構造
約45万戸の小農が国内生産の約90%を担い、残り約10%は大規模エステート(Perfect Daily
Grind)。農家一戸あたりの木の本数は380〜2,000本程度で、多くは1ヘクタール未満。
2018年以降、AMCOS(農業マーケティング協同組合)が生産の95%を管理する体制となり、
小農はAMCOSに登録することで市場アクセス・生産支援・政府支援を受けられる仕組みに
なっている。

### 歴史
1898年、カトリック宣教師がドイツ領時代にキリマンジャロ山麓へコーヒーを持ち込んだ。
1925年にはChagga族が最初の協同組合(KNPA)を設立しロンドン市場へ直接販売。
2018年、法改正によりAMCOSが小農コーヒーの唯一の合法な集荷チャネルとなり、同年
中央オークションを廃止して地域モデルへ移行した(既存本文どおり、今回の調査でも
矛盾する情報は見つからなかった)。

### サブリージョン
- **キリマンジャロ山麓(北部)**: まろやかでマイルド。特定銘柄「キリマンジャロ」の
  産地(ブコバ地区産を除く)。バナナ等との混作、バニラ・チョコレート・プラリネ様の
  風味。
- **南部高地(Mbeya・Ruvuma・Songwe等)**: 標高1,250〜1,400m。国内生産の75〜85%を
  占める最大産地。黒チェリー・タンジェリンの果実味、チョコレート・モラセス・
  キャラメル、絹のようなボディ。

### 出典
Perfect Daily Grind / Royal Coffee(harvestSeason・officialBodyの出典は別途変更なし)

## イエメン

### テロワール
西部・南西部の山岳地帯、ハラズ・バニーマタル・ジャバル・サブル等の高地に手作りの
段々畑(テラス)が広がる。標高は概ね1,500〜2,500m(ハラズ山系は2,200m超)。
灌漑インフラは存在せず、農家と土地との間で世代を超えて培われてきた伝統的な
栽培技術のみに頼る。世界で最も乾燥したコーヒー産地の一つで、短い雨季と長い乾季、
大きな日較差。バニーマタルはハラズに隣接し、同様の標高の恩恵を受け、ダークフルーツ・
タマリンド・野性的でアーシーなスパイスのカップになりやすい。

### 収穫時期
主収穫は10月〜12月(商社により10月〜2月とする資料も)。ほぼ全量ナチュラル(乾式)
精製で、屋根や地面で2〜4週間天日乾燥(既存本文どおり)。

### 農園構造
零細借地農中心で、断片化した数万規模の小規模農園に生産が分散しているため、
ロット間の品質のばらつきが大きい。国全体で15万人規模の小農がコーヒーに生計を
依存しているとされ、労働力の75%を女性が占める(業界報道)。国土の耕地はわずか2.4%で、
灌漑用水の多くが高収益作物カート(qat)栽培に回されている。Qima Coffeeは5,000人超の
小農・55村から調達し、イエメン唯一の完全統合型スペシャルティ事業者・最大の輸出者
(既存本文)。

### 歴史
15世紀、イエメン高地のスーフィー修道士が紅海を渡ってもたらされたコーヒーを栽培し、
夜通しの礼拝の集中力維持のために飲用したのが始まりとされる。1544年、イエメンの
イマームがカート(qat)よりコーヒーを尊いものと宣言し栽培を奨励したとの逸話があり、
これが段々畑をコーヒー畑へ転換させる契機になったとも言われる。16世紀までに港湾都市
モカ(Al-Mokha)が唯一の国際輸出拠点となり、カイロ・コンスタンティノープルを経て
ヴェネツィア・欧州各地へ運ばれた(既存本文の「15世紀に港湾都市モカから世界初の
コーヒー輸出」という部分は、複数資料で16世紀という記載が優勢だったため本文で
時期を調整した)。1700年代初頭には国の収入のほぼ全てがコーヒー輸出だった。2015年の
内戦勃発後に経済が崩壊し、公的な等級認証機関も事実上機能を失った(既存本文どおり)。

### サブリージョン
- **ハラズ**: 国内最高標高帯(最高2,300m超)。深いベリーの甘さ・ワイン様の複雑さ・
  シロップ質のボディ。近年Qima Coffee等の直接貿易でイエメン最大の知名度を持つ
  産地となった。
- **バニーマタル(マタリ)**: ハラズに隣接し同等の高標高。フルボディ、ダークチョコ・
  タマリンド・野性的なスパイス。特定銘柄「モカ・マタリ」の産地。
- **サナニ(サナア西方)**: やや低標高でバランス型・果実味、ワイン様酸味は控えめ。

## ベトナム

### テロワール
中部高原(タイグエン地方)が栽培面積の約9割を占める。現地で「バザン・レッドランド」
と呼ばれる赤色バサルト土壌(全国のバサルト埋蔵量の6割を占めるとされる)が、水はけ・
保水性・養分保持のバランスに優れ、チェリーの緩やかで均質な成熟を促す。ロブスタは
標高約500〜800m。アラビカは北部・南部Da Lat周辺の高標高地(1,000〜1,400m)で
少量栽培。

### 収穫時期
ロブスタの主収穫は10月〜2/3月、ピークは11〜1月。アラビカは9〜11月が主で高地では
4月まで伸びることも(既存本文どおり)。

### 農園構造
中部高原の小農中心で、57.3万戸規模のロブスタ小農が平均農園面積約1.08ha(資料に
より1〜1.5ha程度)を耕作。全農家の85%が2ha未満、63%が1ha未満という細分化構造。
中部高原の栽培面積の85%(約48万ha)は世帯単位の経営で、64万戸超が生産に関わる。
政府はコーヒー栽培リースの割当を1世帯あたり1.2haと定めている。1986年のドイモイ
(経済改革)により、農家が生産物の一部を自ら保有・販売できる権利を得たことで
集約的栽培への転換が進んだ。

### 歴史
1857年にフランス人がアラビカを導入。1914年頃、ダクラク(バンメトート)がロブスタの
「聖域」に選ばれ、バサルト赤土と冷涼な気候により1922年までに広大なコーヒー農園が
形成された。1986年のドイモイ後、生産割当の廃止と土地の私有化が進み、政府も投資を
本格化させたことで、世界第2位の生産国・ロブスタ最大の輸出国へと成長した(既存本文と
整合)。

### サブリージョン
- **ダクラク(Buon Ma Thuot)**: ロブスタの「首都」。力強くコクのある風味。
- **Da Lat/Cau Dat(Lam Dong)**: 高標高アラビカの産地。ブルボン・ティピカ・
  カティモールが中心(カティモールが優勢)。柑橘の酸味・ドライフラワー様の
  フローラル、雨上がりの森を思わせるアーシーな香り。

### 出典
Sweet Maria's / Genuine Origin(varietiesDetailの出典は別途変更なし)
