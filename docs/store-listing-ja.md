## Google Play

### アプリ名
```
Coffeection - コーヒーの検索とレシピの記録
```

### 簡単な説明
```
全国の自家焙煎店のコーヒー豆を、産地・風味・現在地から探せるアプリです。
```

### 詳しい説明
```
全国の自家焙煎店から、まだ出会っていない一杯・一袋を見つけるためのアプリです。

1,800店舗以上の小さな焙煎店と、25,000種類以上のコーヒー豆を一つにまとめました。産地、風味、現在地から探すのはもちろん、なんとなく眺めるだけでも、思いがけない豆に出会えます。

【探す】
・商品名・産地・銘柄・店舗名・住所・駅名で検索
・産地(国)、風味カテゴリ(アプリ独自の分類)、都道府県、自分の★評価で絞り込み
・現在地から近い順、登録したエリア、新規掲載、ランダムで並べ替え
・店舗をGoogleマップで開く

【残す】
・気になる豆を、ワンタップでコレクションに保存
・店頭で買った豆を登録(ネットでは売っていない店頭限定の豆も登録できます)し、パッケージの写真も追加
・★評価、自宅で淹れたコーヒーのテイスティングログ(レシピ・風味・Dial-in Score)、店舗で飲んだ一杯のテイスティングノートを記録
・評価から「好みの傾向」を分析して、おすすめの豆を表示
・コレクション・評価・テイスティングログ・マイツールをファイルにバックアップ・復元

【最新情報】
・コレクションの豆の値下げ・在庫復活、その店舗の新商品を、アプリ内のお知らせで確認
・豆を並べて比較

【学ぶ】
・豆知識: 用語解説、特定銘柄、品種、淹れ方、イベント、競技会
・産地マップと、主要な産地のガイド

【プライバシー重視】
・アカウント登録は不要
・コレクション、評価、ログ、ノート、写真は、すべてお使いの端末内に保存されます
・位置情報は「近い順」の並べ替えにだけ使い、サーバーには送信しません
・現在、広告やアクセス解析は使っていません

【ご案内】
・画面と、豆知識・産地ガイドは、日本語と英語に対応しています(端末の言語に合わせて切り替わり、設定でも変更できます)。
・豆知識・産地ガイドは、公式の資料などで確認できた内容だけを、出典(資料名・リンク・確認日)つきで掲載しています。
・掲載しているのは、日本国内の店舗です。
```

## スクリーンショットのキャプション(案)
画面は、設定で「日本語」にして撮る。サンプルデータ(日本語で作成)を入れた状態が、見栄えがよい。

| # | 画面 | キャプション(案) |
|---|---|---|
| 1 | 商品一覧(近い順) | 全国の自家焙煎店のコーヒー豆を探そう |
| 2 | 絞り込み | 産地・風味・都道府県・自分の評価で絞り込み |
| 3 | 商品詳細 | 豆の情報を、ひと目で |
| 4 | 店舗詳細 | お店を見て、Googleマップで開く |
| 5 | コレクション(登録した商品・写真・★) | 買った豆を、パッケージ写真と一緒に残す |
| 6 | テイスティングログ(Dial-in Score) | 淹れ方を記録して、おいしい条件を見つける |
| 7 | 好みの傾向 | 自分の好みの傾向がわかる |
| 8 | 産地マップ | 世界のコーヒー産地を知る |

- 実在の店舗名・商品名が画面に写る場合は、それらの権利(商標・著作権)の扱いに注意する。サンプルデータなら、架空なので問題ない。
