# 全国の独自EC・STORES・価格表の未登録店発掘 — 判断が必要な項目(2026-11-03)

2026-10-20〜11-03に、食べログの地域別一覧→公式サイト→通販プラットフォームの順で、検索に出にくい未登録の自家焙煎店を全47都道府県で調べた(登録は 1,535店→1,846店、商品 24,869件→30,151件)。
このファイルは、そのうち **ユーザーの判断が必要な項目だけ** をまとめたもの。各店の詳細な見送り理由は `docs/not-implementable-shops.md`、登録した店の一覧は `docs/scraping-progress.md` と `docs/implemented-shops.md` にある。

- **住所・店舗の食い違い**: COFFEE RIN(本店・焙煎は銀座、千葉の新千葉店で登録)、BEAN TREK(特商法と食べログの住所が違う)、プリムビーンズ八ヶ岳(住所が「(仮)」付き。小淵沢の旧住所は閉業の情報あり)、ツチノコーヒー(公式が旧所在地のまま)、疏水焙煎所/KIKKAKEKKO(食べログ名「ナッツと豆の木焙煎所」、別住所の同名ページあり)、THREE MOUNTAIN COFFEE(草津で登録、橿原店は未登録)。
- **COZY COFFEE(神戸)**: 福岡の同名店と区別するため「(神戸)」を付けて登録。
- **福田珈琲店**: 千葉ではなく奈良市秋篠町が所在地(奈良県で登録)。
- **自家焙煎の根拠が弱い**: YAMADA COFFEE OKINAWA、珈琲ソルジャー、雪の子、ISHIBASHI COFFEE、家登珈琲焙煎工房、心留珈琲、林 COFFEESTAND、小屋珈琲(店頭未確認)。
- **価格・重量の基準が特殊**: 北比良焙煎所(生豆200g基準)、天領倉敷珈琲(生豆180g)、アールビー(生豆240g・税別・旧税率表記)、cafe SAKUYA・marQ coffee(生豆量表示)、Y'sコーヒー(複数袋の合計重量・送料込み)、まめや忍・上田珈琲豆焙煎堂(200g)、はらだ珈琲(下限表記)、ポルトボヌール(単位の明記なしで100gと解釈)、BaseCafe(重量null)、クレイズcoffee・山鼻Beans(重量null)。

- **豆煎人(浜松)**: GitHub Actions からの取得で403が出る可能性があり、CIでの再検証が必要。

## 5. 運用上の判断

1. 今回の発掘で追加した `scraper/scrape_*.py`(251本)を `.github/workflows/scrape-shops.yml` に登録するか。登録しない場合は `aggregate_shops.py` が保存済みの `data_*.json` を使えず、CIでの再取得ができない。Shopify系はCIでも429が出やすい。
2. `scraper/` 配下の未追跡の一時ファイル(`m_*_tmp.py`、`*_tmp.py`、`base_dump.*` など)の削除可否。コミットはしていない。
3. 再発掘を続けるか。食べログに公式URLがなくInstagramのみの店(販売先と価格が確認できない店)が各県に多数あり、未登録のまま。Instagramは自動取得が禁止のため、店ごとの手作業での確認が要る。
