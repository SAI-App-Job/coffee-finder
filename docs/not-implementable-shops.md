# 実装見送り店舗ログ

自家焙煎コーヒー豆専門店として実在確認したが、スクレイパーを実装しなかった
店舗の記録。目的は同じ店舗を将来のエリア調査で重複して調べ直さないこと。
実在確認そのものに失敗した(存在しない店名等)場合は載せない。

フォーマット:

```
## [店舗名]（所在地、確認日）
- 実在確認: ...(Googleマップの評価・口コミ数、公式サイト等)
- 見送り理由: ...
```

---

## ザグリ珈琲（東京都杉並区阿佐谷北、2026-09-03）
- 実在確認: 住所・Qグレーダー資格保有の記載と一致を確認済み。
- 見送り理由: サイト(zaguri.tokyo、WordPress)はコーヒーの化学・焙煎・
  カッピング等の教育目的のブログ/用語集で、ショップ・カート機能が
  一切見つからなかった。

## A FEW WORDS COFFEE（東京都新宿区東新宿、2026-09-03）
- 実在確認: 実店舗サイト(afewwordscoffee.com)からリンクされる実在の
  BASEショップ(afwc.base.shop)を確認済み。
- 見送り理由: 全4カテゴリ・21商品を確認したところ、すべてが定期便(サブスク)
  または「セレクト2〜3種」「おまかせ」等の複数豆アソートで、特定の一豆を
  指す単品SKUが1件も存在しなかった。

## 珈琲焙煎工房FLUTTER（東京都新宿区西新宿、2026-09-03）
- 実在確認: Googleマップ★4.2(101件の口コミ)、住所一致を確認済み
  (西新宿8-4-1 ナルコビル102)。運営会社の異なる2サイト
  (carebe.jp、nitor.co.jp)がいずれも同一店舗を指すことも確認済み。
- 見送り理由: 両サイトとも情報サイトのみでオンラインショップ機能が無い。
  carebe.jpの「BEANS」ページには「今月の珈琲豆は、Instagramでご紹介して
  います」と明記されており、価格表・カートが存在しない。

## 常盤珈琲焙煎所（東京都港区、2026-09-03）
- 実在確認: tokiwacoffee.com(情報サイト)から実際の通販サイト
  (tokiwacoffee.shop-pro.jp、カラーミーショップ)を確認済み。
- 見送り理由: 「コーヒー豆」カテゴリだけで1,329件という規模のカタログで、
  GitHub Actionsでの実行時間・対象サイトへの負荷の観点から自動スクレイピングが
  現実的でない。

## Un Cafe Sucre（東京都墨田区東向島、2026-09-03）
- 実在確認: cafe-sucre.tokyo(Shopify)を確認済み。
- 見送り理由: 同一Shopifyストア内に、無関係な別ブランド・別拠点(「軽井沢
  焙煎所オーガニック」=長野県の店舗限定、「イノセントコーヒー」=別ベンダー)の
  商品や、定期便・ギフトセット・ミルクブリュー濃縮液等が複雑に混在しており
  (全213商品)、対象の墨田区店舗の単品豆だけを確実に絞り込むことが困難と
  判断した。

## 自家焙煎珈琲まるたま（東京都江東区牡丹、2026-09-03）
- 実在確認: Googleマップ★4.7(33件の口コミ)、STORESショップ
  (apotheosispg.stores.jp)を確認済み。
- 見送り理由: STORESプラットフォームは完全にクライアントサイドJS描画の
  SPAで、サーバー側の静的HTMLに商品データが一切含まれない(タイトルタグすら
  空)。requests+BeautifulSoupでは取得不可能(吉田珈琲焙煎所と同じ問題、
  そちらは手動データ登録で対応済み)。

## 1.414 Coffee Roastery（東京都江東区扇橋、2026-09-03）

## 宮越屋珈琲（東京都港区新橋ほか、2026-09-04）
- 実在確認: miyakoshiya-coffee.co.jpで店舗一覧を確認済み。
- 見送り理由: 千歳・恵比寿・銀座・日比谷・神田明神・霞が関・町田・目白・
  日本橋・札幌・仙台等、22店舗以上を展開する中堅チェーンであり、この
  プロジェクトが対象とする独立系自家焙煎専門店の範囲を超える。オンライン
  ショップも見つからなかった。

## 三十間（東京都中央区銀座、2026-09-04）
- 実在確認: sanjikken.net(WordPress)、Google Maps上の店舗情報と一致。
- 見送り理由: 「コーヒー豆」紹介ページ(/coffeebeans/)はあるが価格表示・
  カート等のオンライン販売機能が一切無い。

## EXPERTO（東京都中央区銀座、2026-09-04）
- 実在確認: 実店舗「CAFE EXPERTO」がGINZA SIX B2に実在することを複数の
  独立情報源(食べログ、ippin、Instagram)で確認済み。
- 見送り理由: ユーザー指定ドメイン(experto.cafe)はDNS解決不可(消滅)。
  代替のオンラインショップURLも検索したが見つからなかった(GINZA SIX
  館内の対面販売が中心と推測される)。

## 十一房珈琲店（東京都中央区銀座、2026-09-04）
- 実在確認: Googleマップ★4.0(548件の口コミ)、1978年創業の実店舗を確認済み。
- 見送り理由: Google検索のAI要約で「公式のオンラインショップや通販を
  行っていません」と明記(店頭販売のみ)。

## FUKAGAWAGEISHA（東京都江東区、2026-09-04）
- 実在確認: 「江戸東京コーヒー FUKAGAWA GEISHA」という商品名で流通して
  いることを確認済み。
- 見送り理由: 独立した店舗・ブランドではなく、実装済みの
  カフェ・デザールピコが焙煎・販売する商品ライン(ドリップバッグ)の1つ
  であることが判明。対象店舗としては新規性が無い。
