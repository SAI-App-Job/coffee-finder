# 実装見送り店舗ログ

自家焙煎コーヒー豆専門店として実在確認したが、スクレイパー・手動データ
登録のいずれでも収録しなかった店舗の記録。目的は同じ店舗を将来のエリア
調査で重複して調べ直さないこと。実在確認そのものに失敗した(存在しない
店名等)場合は載せない。

**重要**: オンライン販売が無いことは単独では見送り理由にならない
(`scraper/manual/README.md`の手動入力ルートで対応可能)。見送るのは、
実店舗での豆販売自体が確認できない場合、産地・価格等の商品情報が
(オンライン・オフライン問わず)何ら確認できない場合、11店舗以上の
チェーンである場合、閉店済みの場合、独立店舗ではない場合等に限る。

フォーマット:

```
## [店舗名]（所在地、確認日）
- 実在確認: ...(Googleマップの評価・口コミ数、公式サイト等)
- 見送り理由: ...
```

---

## 珈琲焙煎工房FLUTTER（東京都新宿区西新宿、2026-09-03、2026-09-04再調査）
- 実在確認: Googleマップ★4.2(101件の口コミ)、住所一致を確認済み
  (西新宿8-4-1 ナルコビル102)。Instagram(@flt_coffee、フォロワー1,900人超、
  「30種類の珈琲豆販売中」)で活発に運用されており、店頭で実際に豆を
  販売していることは確実(価格帯「100g：700円 200g：1300円」等の投稿を
  検索スニペット経由で複数確認、直近では「ベネズエラ産メリダ エル・バレ
  Caturra FULLCITY ROAST」等の具体的な入荷情報も見つかった)。
- 見送り理由: 公式サイト(carebe.jp/nitor.co.jp)はオンラインショップ機能が
  無く完全にJS描画のSPA(静的HTMLに内容が無い)。商品の現行ラインナップは
  Instagram投稿でのみ告知されているが、投稿一覧はログインしないと閲覧
  できず、検索スニペット経由では断片的な情報(一部の産地名・価格帯)しか
  収集できなかった。手動データ登録の基準(産地・価格等が確認できること)を
  部分的には満たすが、現行30種類の完全なラインナップを再現するだけの
  情報が無いため、不正確なデータを収録するよりは見送りとした。Instagram
  アカウントへのログインアクセスがあれば再調査可能。

## EXPERTO（東京都中央区銀座、2026-09-04）
- 実在確認: 実店舗「CAFE EXPERTO」がGINZA SIX B2に実在することを複数の
  独立情報源(食べログ、ippin、Instagram、2017年開業時のフォートラベル記事)
  で確認済み。「販売するコーヒー豆は全て品種と生産国を明記致します」との
  開業時の方針表明もあり、豆売り自体は確実。
- 見送り理由: ユーザー指定ドメイン(experto.cafe)はDNS解決不可(消滅)。
  代替のオンラインショップも見つからず、Instagram(@cafe_experto、
  フォロワー199人)は投稿一覧が未ログインで閲覧できない。現行の具体的な
  商品名・価格を示す情報源(2017年の開業告知以外)を見つけられなかった
  ため、手動データ登録の基準を満たせず見送りとした。

## ARiSE COFFEE ROASTERS（東京都江東区平野(清澄白河)、2026-09-04）
- 実在確認: Googleマップ★4.4(672件の口コミ)、公式サイト(arisecoffee.jp)。
  自己紹介文に「焙煎豆販売、ドリップコーヒーの提供が中心」と明記されて
  おり、焙煎豆の店頭販売が主業務であることは確実。
- 見送り理由: 公式サイトのMENU欄は「コーヒー豆 ￥1,050〜」という価格帯
  のみで、個別の産地・銘柄名の記載が無い。X(@arisecoffee)・Instagram
  (@arisecoffee)とも具体的な商品情報を投稿しておらず(Xは店舗の雑談・
  趣味の投稿が中心)、Instagramは未ログインで投稿一覧が閲覧できなかった。
  現時点では「豆を売っている」以上の具体的な産地・価格情報を確認できず、
  手動データ登録の基準を満たせないため見送りとした。

## 三十間（東京都中央区銀座、2026-09-04再調査で判明)
- 実在確認: sanjikken.net(WordPress)、Google Maps上の店舗情報と一致。
- 見送り理由: 当初「オンライン販売が無い」を理由に見送っていたが、
  再調査したところそもそも自家焙煎店ではないことが判明。公式サイトに
  「三十間のコーヒー豆は系列店の「やなか珈琲店」で焙煎した新鮮な状態の
  コーヒー豆だけを使用しています」と明記されており、三十間自身は焙煎を
  行わず系列の別会社(やなか珈琲)が焙煎した豆を仕入れて店内でドリンクとして
  提供するカフェ(豆売り自体もしていない、メニューは全て飲料)。この
  プロジェクトが対象とする「自家焙煎コーヒー豆専門店」の範囲外。

## 常盤珈琲焙煎所（東京都港区、2026-09-03）
- 実在確認: tokiwacoffee.com(情報サイト)から実際の通販サイト
  (tokiwacoffee.shop-pro.jp、カラーミーショップ)を確認済み。
- 見送り理由: 「コーヒー豆」カテゴリだけで1,329件という規模のカタログで、
  GitHub Actionsでの実行時間・対象サイトへの負荷の観点から自動スクレイピングが
  現実的でない。

## Un Cafe Sucre（東京都墨田区東向島、2026-09-03）
- 実在確認: cafe-sucre.tokyo(Shopify)を確認済み。
- 見送り理由: 同一Shopifyストア内に、無関係な別ブランド・別拠点(「軽井沢
  焙煎所オーガニック」=長野県の店舗限定、「イノセントコーヒー」=別ベンダー)の
  商品や、定期便・ギフトセット・ミルクブリュー濃縮液等が複雑に混在しており
  (全213商品)、対象の墨田区店舗の単品豆だけを確実に絞り込むことが困難と
  判断した。

## 自家焙煎珈琲まるたま（東京都江東区牡丹、2026-09-03）
- 実在確認: Googleマップ★4.7(33件の口コミ)、STORESショップ
  (apotheosispg.stores.jp)を確認済み。
- 見送り理由: STORESプラットフォームは完全にクライアントサイドJS描画の
  SPAで、サーバー側の静的HTMLに商品データが一切含まれない(タイトルタグすら
  空)。requests+BeautifulSoupでは取得不可能(吉田珈琲焙煎所と同じ問題、
  そちらは手動データ登録で対応済み)。オンラインショップ自体は実在するため
  「見送り」というより「要・別手段での取得」に近いが、現状はブラウザでの
  目視確認による手動データ化を行っていない。
