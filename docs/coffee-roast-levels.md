# 焙煎度(ロースト)調査まとめ

産地・精製方法・グレードとは独立した「焙煎」という属性を整理。日本の自家焙煎店では、この8段階表記が商品名に頻出する(例:「グアテマラ SHB シティロースト」)。

---

## 1. 日本式8段階ローストの一覧

浅煎り→深煎りの順。名称の由来は1920年代のアメリカで使われていた分類がベースとされる。

| # | 名称 | 段階 | 豆の状態・焙煎の進行 | 味わいの傾向 |
|---|---|---|---|---|
| 1 | **ライトロースト** | 極浅煎り | 1ハゼ前後で煎り止め。うっすら色づく程度。ほとんど流通せず、産地の味の違いを見るカッピング用途で使われることが多い | コーヒーらしい香りより青っぽい香りが強い |
| 2 | **シナモンロースト** | 浅煎り | ライトよりやや進行。豆の色がシナモン色になることが名前の由来 | 軽くすっきり、酸味が際立つ。好みが分かれる |
| 3 | **ミディアムロースト** | 中浅煎り | 1ハゼが終わる頃。通称アメリカンロースト | 酸味優位だがすっきりした香ばしさも出始める |
| 4 | **ハイロースト** | 中煎り | 2ハゼの手前〜最中。日本で「中煎り」として最も広く認知される段階 | 酸味と苦味のバランスが取れる。後味にまろやかさ |
| 5 | **シティロースト** | 中深煎り | 2ハゼ終了、色もかなり濃くなる。「シティ」はニューヨークシティが好んだ焙煎度に由来 | プロにも好まれる黄金バランスとされる |
| 6 | **フルシティロースト** | 中深〜深煎り | 2ハゼが収束しさらに進行。油分が表面に滲みテカテカした光沢が出る | 力強いコク。アイスコーヒーやエスプレッソに向く |
| 7 | **フレンチロースト** | 深煎り | 表面の油分がかなり滲み出る | 強い苦味とコク |
| 8 | **イタリアンロースト** | 極深煎り | 焙煎の最終段階。豆は黒に近い | 最も強い苦味。カフェインは加熱で飛ぶため深煎りほど少なくなる傾向 |

---

## 2. 焙煎の進行と「ハゼ(クラック)」の関係

焙煎中、豆から聞こえる爆ぜる音を「ハゼ」と呼び、焙煎度の目安になる。

- **1ハゼ**: 豆の水分が飛んだ後、内部の炭酸ガスにより膨張してパチパチと弾ける音。ミディアム〜ハイローストの境目あたりで発生
- **2ハゼ**: さらに焙煎が進み、色が濃くなり油分も出てきた状態でピチピチと高い音がする。シティ〜フルシティローストの境目あたりで発生

店舗の商品説明で「2ハゼ後」「1ハゼ直後で煎り止め」のような表現が使われる場合、この基準で焙煎度を推定できる。

---

## 3. 客観指標: アグトロン値(Agtron Number)

感覚的な「シティ」「フルシティ」といった呼称は焙煎士によって判断がぶれるため、**赤外線で豆の色を測定する客観指標**としてアグトロン値が使われる。数値が大きいほど浅煎り、小さいほど深煎り。

- アメリカのAgtron社が開発した食品用分光光度計による測定値。SCA(スペシャルティコーヒー協会)のカッピング規約でも採用されている
- 日本では同様の数値を計測できるLighttells社等の製品が普及

### 対応表(あくまで一例。測定機器・ロースターにより数値は変動)

| 日本式8段階 | アグトロン値の目安 |
|---|---|
| ライトロースト | 80〜70 |
| シナモンロースト | 70〜58 |
| ミディアムロースト | 58〜50 |
| ハイロースト | 50〜45 |
| シティロースト | 45〜40 |
| フルシティロースト | 40〜35 |
| フレンチロースト | 35〜25 |
| イタリアンロースト | 25未満 |

### SCA独自の8段階(参考: 日本式とは名称も区切りも異なる)

| SCA名称 | アグトロン値 |
|---|---|
| Extremely Light | 91〜130 |
| Very Light | 81〜90 |
| Light | 71〜80 |
| Medium Light | 61〜70 |
| Medium | 51〜60 |
| Moderately Dark | 41〜50 |
| Dark | 31〜40 |
| Very Dark | 0〜30 |

※SCAのサンプルロースト規約では「グルメ」63.0、「コマーシャル」48.0という基準値(±1.0)も定義されている。

**注意点**: 日本式8段階とSCAの8段階は**区分の考え方も名称も異なる**別系統の分類。店舗が「ミディアムロースト」と書いていても、日本式(アグトロン58〜50、中浅煎り)なのかSCA式(アグトロン51〜60、中間的な立ち位置)なのかで実際の焙煎度がずれる可能性がある。海外ロースターの表記を扱う場合は特に注意。

## 4. 歴史的背景(豆知識)

- 8段階の分類は1920年代のアメリカで使われていた分類がベースとされる
- 当時は地域ごとに好みの焙煎度が大きく異なっていた: イギリスはライトロースト(1ハゼ直前で煎り止め)、フランスは表面に油が滲み出るほどの深煎り(フレンチロースト)、イタリアは炭っぽくなるほどの深煎り(イタリアンロースト)。ドイツはフランスと同程度、北欧はイタリアよりさらに深煎りだったとされる
- アメリカ国内でも地域差が大きく、ボストンや西海岸ではシナモン〜ライト、東部はハイ〜フルシティ、南部はフレンチ以上ともっとも深煎りだったという記録がある
- 「シティロースト」の名称は、この焙煎度がニューヨーク・シティで最も好まれたことに由来する

## 5. データモデルへの落とし込み

これで商品を構成する属性が出揃った形になる。

```
商品 = {
  産地(国/地域/銘柄),
  精製方法(ウォッシュド/ナチュラル/ハニー等),
  国別グレード表記(国とセットで保持),
  焙煎度(日本式8段階 or アグトロン値),
  (任意)スペシャルティ認定フラグ/カッピングスコア,
  (任意)認証タグ(オーガニック/フェアトレード/COE)
}
```

- 焙煎度は**店舗が独自に選ぶ工程**であり、産地・精製方法・グレードとは完全に独立した属性。同じ「グアテマラ SHB」でも店舗によってシティローストだったりフレンチローストだったりする
- 店舗の商品名パース時、8段階の名称(ライト/シナモン/ミディアム/ハイ/シティ/フルシティ/フレンチ/イタリアン)をキーワードマッチングで抽出するのが最も簡単。数値(アグトロン値)を明記する店舗は少数派と想定されるため、名称ベースの抽出を主軸にするのが現実的
- 「中煎り」「深煎り」のような大分類表記(ライト/シナモン/ミディアム→浅煎り、ハイ/シティ→中煎り、フルシティ→中深煎り、フレンチ/イタリアン→深煎り、という店舗もあれば区切り方が違う店舗もある)も併記されるケースがあるため、大分類とのマッピングテーブルも用意しておくと取りこぼしが減る
