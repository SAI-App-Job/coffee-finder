# タンザニア グレード規格 調査まとめ

ORIGIN_GUIDEのタンザニアへのgradeSystem追加のための一次資料調査。既存のtanzania原稿(terroir/varietiesDetail/farmStructure/history/subRegions/officialBody)には等級名・スクリーンサイズ等のグレード情報が一切含まれていなかったため、ペルー・エルサルバドル・ルワンダのときと同様、新規の一次資料調査が必要と判断して実施した。

## 調査結果: タンザニア独自の規格ではなく東アフリカ共通規格(EAS)を採用

**一次資料**: [EAST AFRICAN STANDARD EAS 130:1999「Green coffee beans – Specification」](https://law.resource.org/pub/eac/ibr/eas.130.1999.html)(東アフリカコミュニティ(EAC)規格。本部はタンザニア・アルーシャのAICC Building。運用は東アフリカ標準委員会と各国の国家標準機関)

タンザニアはケニアのように独自の等級記号を新たに作ったわけではなく、EAC加盟国共通のEAS 130:1999をコーヒー生豆規格として採用している(ウガンダの2018年ICO提出資料でも同一のEAS 130:1999への準拠が明記されている)。

### スクリーンサイズによる等級区分

| 等級 | 説明 | スクリーンサイズ |
|---|---|---|
| E(象豆) | 遺伝的欠陥で2つの豆が結合した豆 | ふるい21番保持(8.3mm) |
| PB(ピーベリー) | チェリー内に通常2つできる種子が1つのみ発達した豆 | ふるい17番保持・12番通過(4.76mm) |
| AA | 平豆(最大サイズ) | ふるい21番通過・18番保持(7.2mm) |
| AB | 平豆 | ふるい18番通過・16番保持(6.35mm) |
| C | 小粒 | ふるい16番通過・10番保持(3.96mm) |
| TT | AA/AB/Eから空気選別で分離された低密度豆 | - |
| T | 最小サイズ、割れ豆・小粒Cを含む | ふるい7番通過(2.9mm) |

各等級は「豆の最低95%が当該サイズ区分に該当すること」が条件。

### カップ品質・最終等級クラス

カップ品質はFine/Good/Fair to good(完全FAQ)/FAQ/Fair/Poorの段階で評価され、これらと欠点数・外観を組み合わせた最終品質クラス1〜10(クラス1〜6は洗浄豆、7〜10は未洗浄のムブニ等低品質帯を含む)に分類される。

**傍証**: Tanzania Coffee Board自身の「Tanzania Coffee Industry Development Strategy 2020–2025」(2021年6月)内でも、水洗アラビカの品質実績評価指標として「% of washed Arabica coffee produced as class 1-6」という表記が使われており、EAS由来のクラス1〜6体系がタンザニア国内の実務でも実際に使われていることが確認できる。ただし同戦略文書自体はグレードの詳細な区分定義(スクリーンサイズ等)そのものは記載していない(等級表の一次資料はEAS 130:1999)。

なお、Tanzania Coffee Board「Trading Manual for Coffee Auction Market」も参照したが、これは競売手続きに関する文書であり、等級の定義そのものは記載されていなかった(オークション目録に「grade」欄がある、という言及のみ)。
