# 精選方法・各国グレード規格 調査まとめ

産地マスタ(coffee-origin-master-draft.md)を補完する「タグ」情報として、精選方法とグレード表記を整理。
店舗の商品名パースで「産地」とは別軸のタグとして抽出することを想定。

> **用語の訂正**: コーヒーチェリーから生豆を取り出す工程は正しくは「精選(せいせん)」。
> 「精製(せいせい)」は本来「混合物を純物質にする工程」を指す一般用語で、コーヒー業界では
> 混同されやすい誤用(または慣用的な代用表記)。ただし実店舗の商品説明では「精製処理：〇〇」
> という表記も実際に使われているため、パーサー側は「精選」「精製」の両方をキーワードとして
> 受け付ける設計にしている。

---

## 1. 精選方法(プロセス)

コーヒーチェリーから生豆を取り出す工程。同じ産地でも精選方法によって商品名・風味説明が変わるため、産地とは独立した属性として持たせるのが良い。

| 精選方法 | 別名 | 工程の要点 | 風味傾向 |
|---|---|---|---|
| **ウォッシュド** | 水洗式、フルウォッシュド | 果肉除去→水槽で発酵・ミューシレージ除去→水洗い→乾燥 | クリーンで明瞭な酸味、雑味が少ない |
| **ナチュラル** | 乾燥式、アンウォッシュド | チェリーのまま天日/機械乾燥→まとめて脱穀 | フルーティで甘みが強い、個性が出やすい |
| **ハニー** | パルプドナチュラル | 果肉除去のみ行い、ミューシレージを残したまま乾燥。乾燥中の色でホワイト/イエロー/レッド/ブラックに細分 | ウォッシュドとナチュラルの中間。ブラックに近いほどナチュラル寄り |
| **ウェットハルド** | スマトラ式、半水洗式、ギリンバサ(Giling Basah) | インドネシア(スマトラ島・スラウェシ島など)特有。①果皮除去(ルワクという機械でパルピング)→②農家段階で水分値40%前後まで1次乾燥(この状態の豆をGabah/Asalanと呼ぶ)→③集荷業者が水分値30〜35%という通常より高い含水率のまま脱殻(=ウェットハル。通常は水分12〜13%まで乾燥してから脱殻する)→④脱殻後の生豆で2次乾燥、という2段階乾燥が最大の特徴 | 重厚なボディ、土っぽい(アーシー)風味。生豆が深緑色になるのも特徴。高温多雨で長期乾燥が難しい気候・小規模農家中心という社会的背景から発展したとされる |
| **アナエロビック** | 嫌気性発酵 | 密閉容器内でチェリーを発酵させる実験的処理。近年COEなどで増加傾向 | 個性的でワインやフルーツ様の強い風味。銘柄名に明記されることが多い(例:「〇〇 アナエロビックナチュラル」) |

### 国別の主流精選方法(傾向)
- **中南米**: ブラジルはパルプドナチュラル/ナチュラルが主流(平地・機械化)。コロンビア・グアテマラ・コスタリカなどはフルウォッシュドが伝統的
- **アフリカ**: エチオピアは地域によって混在(イルガチェフェはウォッシュド中心、ハラー・シダモはナチュラル中心)。ケニア・タンザニアはウォッシュド中心
- **インドネシア**: ウェットハルド(ギリンバサ)が伝統的

## 2. 各国グレード(等級)規格

グレードの判定基準は国ごとに異なり、大きく4種類の基準(**標高／スクリーンサイズ／欠点数／カップ品質**)のいずれか、または組み合わせで決まる。同じ「G1」「AA」でも国が違えば意味が異なる点に注意。

### 標高で格付けする国
| 国 | 最上位グレード | 基準 |
|---|---|---|
| グアテマラ | SHB(Strictly Hard Bean) | 標高約1,350〜1,500m以上 |
| コスタリカ | SHB / SHG(Strictly High Grown) | 標高約1,170〜1,620m以上。太平洋側/大西洋側の斜面でも区分 |
| メキシコ・ホンジュラス | SHG(Strictly High Grown) | 標高の高さで区分。品質・トレーサビリティとは直接連動しない点に留意 |
| エルサルバドル | SHG | メキシコ・ホンジュラスと同様の考え方 |

### スクリーンサイズ(豆の粒の大きさ)で格付けする国
| 国 | 最上位グレード表記 | 備考 |
|---|---|---|
| コロンビア | スプレモ(Supremo) / エキセルソ(Excelso) | 出荷前の品質管理が厳格なため、サイズのみで評価される |
| タンザニア | AA | スクリーン18以上が目安 |
| ケニア | AA | AA→A→AB…と続く。ピーベリー(PB)は別枠評価 |
| ブラジル | S13〜S20程度のスクリーン表記 | 後述の欠点数評価(No.表記)と併用されることが多い |
| ハワイ(コナ) | エクストラファンシー、ファンシー、No.1 | スクリーンサイズ+欠点数の複合評価 |

### 欠点数で格付けする国
| 国 | 表記 | 基準 |
|---|---|---|
| ブラジル | No.2〜No.8 | 300gサンプル中の欠点(欠点豆・異物)を点数化。No.2(4点以下)が実質最上位、No.1は理論上のみ存在 |
| エチオピア | G1〜G5(輸出等級。国内向けはG9まで) | 300g中の欠点豆数で判定。G1:0〜3個、G2:4〜12個、G3:13〜27個、G4:28〜45個、G5:46〜90個。G1はイルガチェフェのウォッシュドの一部にのみ付与される特別格付け |
| インドネシア(マンデリン等) | G1〜G6 | エチオピアと同じ表記だが基準が異なり、G1でも欠点豆0〜11個程度と、ウェットハルド特有の欠け豆が出やすい分やや緩め |
| ベトナム | スクリーンサイズ+欠点数の複合 | ロブスタ主体で等級表記は流通上あまり重視されない傾向 |

### 産地(地区)+固有規格で格付けされる特殊銘柄
| 銘柄 | 国/地区 | グレード構成 |
|---|---|---|
| ブルーマウンテン | ジャマイカ | No.1(最高級・木樽出荷)→No.2→No.3(主にブレンド用)→ピーベリー(丸豆)→トリアージ(ブルーマウンテンセレクトとも呼ばれ麻袋出荷) |
| クリスタルマウンテン | ジャマイカ(ブルーマウンテン地区外の高地) | ブルーマウンテンと同地区法の枠外だが、ブルーマウンテンに準じた栽培・精製基準で認定 |
| ハイマウンテン | ジャマイカ(ブルーマウンテン地区外) | スプリーム→ピーベリー→ジャマイカプライム→ジャマイカプライムピーベリー→ジャマイカセレクト |

## 3. 業界団体情報との突合

### 全日本コーヒー協会(AJCA)
豆の等級・規格を定める団体ではない。1980年設立の業界団体で、広報・消費振興、科学情報、安全安心、統計情報(輸入量・消費動向など)の収集提供が主な活動。今回の産地マスタ・グレード分類には直接関与しない。

### 日本スペシャルティコーヒー協会(SCAJ)
国別グレード(G1/SHB/AA等)とは完全に独立した、カッピングによる品質評価の枠組みを持つ。

- COE方式のカッピングフォームを採用: 8項目をそれぞれ0〜8点で採点し、合計に基礎点36点を加算して100点満点化
- **合計80点以上を獲得したコーヒーのみ「スペシャルティコーヒー」を名乗れる**(84点以上は「トップスペシャルティ」と呼ばれることも)
- 国別グレード表記(産地の等級)とスペシャルティ認定は別軸の情報であり、両方を商品が持ちうる(例:「エチオピア イルガチェフェ G1 スペシャルティ」)

→ データモデル上は「国別グレード」とは別に、**カッピングスコアに基づく品質フラグ**を独立属性として持たせるのが正確。

## 4. データモデルへの落とし込み案

産地マスタと組み合わせると、1商品は以下のようなタグの組み合わせで表現できそうです。

```
商品 = { 産地(国/地域/銘柄), 精選方法, 国別グレード表記, (任意)スペシャルティ認定フラグ/カッピングスコア, (任意)認証タグ(オーガニック/フェアトレード/COE) }
```

- **精選方法**とグレードは商品名から独立して抽出可能なことが多い(例:「エチオピア イルガチェフェ G2 ウォッシュド」→ 産地:エチオピア/イルガチェフェ、グレード:G2、精選方法:ウォッシュド)
- ただし**グレード表記の意味は国ごとに異なる**ため、グレードを正規化・比較する場合は「国+グレード記号」をセットで保持する必要がある(例:単に「G2」だけを保存すると、エチオピアかインドネシアか判別できない)
- ブルーマウンテンのように「銘柄自体がグレード体系を内包する」ケースは、産地マスタ側の銘柄情報とグレード情報が重複しうるので、パース時にどちらを優先するかのルールが必要になりそう
