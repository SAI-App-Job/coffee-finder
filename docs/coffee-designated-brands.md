# 「特定銘柄」14種 調査まとめ

産地マスタ・グレード・焙煎度とは別軸で存在する、**日本国内の表示ルールとしての「銘柄」規制**を整理。

---

## 1. 特定銘柄とは何か

- **策定主体**: 全日本コーヒー公正取引協議会
- **法的根拠**: 公正取引委員会が認定した「レギュラーコーヒー及びインスタントコーヒーの表示に関する公正競争規約、同施行規則」
- **成立の背景**: 昭和50年代、コーヒーの銘柄・産地表示に混乱があったことを受け、業界団体が表示ルールを整備
- **重要な性質**: これは**日本国内の業界自主規制**であり、生産国や産地が公的に証明した銘柄ではない(ジャマイカのブルーマウンテンのように、生産国側が別途ブランド保護制度を持つケースもあるが、それとは別の枠組み)
- **ブレンド使用ルール**: 生豆換算で**30%以上**その銘柄の豆を含んでいなければ、商品名にその銘柄名を表示できない

→ 産地マスタ・国別グレード・SCAJスペシャルティ認定とはまったく別の、**「日本国内で名乗って良いかどうか」を規制する第4の軸**として扱う。

---

## 2. 特定銘柄14種の定義

| # | 銘柄 | 定義 |
|---|---|---|
| 1 | **ブルーマウンテン** | ジャマイカ・ブルーマウンテン地区にて生産されたアラビカコーヒー豆 |
| 2 | **ハイマウンテン** | ジャマイカ・ハイマウンテン地区にて生産されたアラビカコーヒー豆 |
| 3 | **ジャマイカ** | ジャマイカにて生産されたアラビカコーヒー豆のうち、ブルーマウンテン及びハイマウンテン以外のもの |
| 4 | **クリスタルマウンテン** | **キューバ**にて生産された同国輸出規格に基づくアラビカコーヒー豆 |
| 5 | **グアテマラアンティグア** | グアテマラ・アンティグア地区にて生産されたアラビカコーヒー豆 |
| 6 | **コロンビアスプレモ** | コロンビアにて生産された同国輸出規格に基づくアラビカコーヒー豆 |
| 7 | **モカ・ハラー** | エチオピア・ハラー地区にて生産されたアラビカコーヒー豆 |
| 8 | **モカ・マタリ** | イエメンにて生産されたアラビカコーヒー豆 |
| 9 | **キリマンジャロ** | タンザニアにて生産されたアラビカコーヒー豆(ブコバ地区産を除く) |
| 10 | **トラジャ** | インドネシア・スラウェシ島トラジャ地区にて生産されたアラビカコーヒー豆 |
| 11 | **カロシ** | インドネシア・スラウェシ島カロシ地区にて生産されたアラビカコーヒー豆 |
| 12 | **ガヨマウンテン** | インドネシア・スマトラ島タケンゴン地区にて生産されたアラビカコーヒー豆 |
| 13 | **マンデリン** | インドネシア北スマトラ州及びアチェ州(ガヨマウンテン生産地区=タケンゴン周辺を除く)にて生産されたアラビカコーヒー豆 |
| 14 | **ハワイコナ** | アメリカ・ハワイ州南コナ地区及び北コナ地区にて生産されたアラビカコーヒー豆 |

## 3. 産地マスタとの整合性チェック

これまで作成した産地マスタ(coffee-origin-master-draft.md)との照合結果:

| 特定銘柄 | 産地マスタ上の扱い | 整合性 |
|---|---|---|
| ブルーマウンテン | ジャマイカ/ブルーマウンテン山系 | ○ 一致 |
| クリスタルマウンテン | ~~ジャマイカ~~ → **キューバに訂正** | ✕ 誤り(訂正済み) |
| モカ・ハラー | エチオピア/ハラー | ○ 一致(産地マスタでは「ハラー」表記のみだったが「モカ・ハラー」が正式銘柄名) |
| モカ・マタリ | イエメン/マタリ地区 | ○ 一致 |
| キリマンジャロ | タンザニア/キリマンジャロ山麓 | △ ほぼ一致だが「ブコバ地区産を除く」という除外条件が産地マスタに未反映だった |
| マンデリン | インドネシア/スマトラ島 | △ 一致だが「ガヨマウンテン地区(タケンゴン周辺)を除く」という重要な除外条件があり、マンデリンとガヨマウンテンは特定銘柄上は明確に別物として区別されている |
| トラジャ/カロシ | インドネシア/スラウェシ島(セレベス) | △ 産地マスタでは「セレベス」と一括りにしていたが、特定銘柄ではトラジャ地区とカロシ地区は別銘柄として区別される |
| ハワイコナ | ハワイ/コナ地区 | ○ 一致 |
| グアテマラアンティグア | グアテマラ/アンティグア | ○ 一致 |
| コロンビアスプレモ | コロンビア(産地マスタでは国レベルのみ) | △ 「スプレモ」はコロンビアのグレード表記でもあり特定銘柄名でもある、二重の意味を持つ表記 |
| ハイマウンテン/ジャマイカ | (産地マスタ未収録) | 追加要 |

→ **「マンデリン」と「ガヨマウンテン」が特定銘柄上は排他的な関係**にある点は、データモデル上とても重要。同じ北スマトラ島産でも、タケンゴン周辺(ガヨマウンテン地区)産かそれ以外かで、名乗れる銘柄名が変わる。

## 4. データモデルへの反映方針

これで商品を構成する属性がもう1軸増える。

```
商品 = {
  産地(国/地域/銘柄),
  精製方法,
  国別グレード表記,
  焙煎度,
  (任意)特定銘柄フラグ(全日本コーヒー公正取引協議会の14銘柄のいずれかに該当する場合。ブレンドなら生豆30%以上の混入が必要という表示ルール付き),
  (任意)スペシャルティ認定フラグ/カッピングスコア,
  (任意)認証タグ
}
```

- 特定銘柄は「産地(国・地域)」から**自動的に導出できる場合が多い**(例:タンザニア産→キリマンジャロを名乗れる、ただしブコバ地区産は除く)。産地マスタと特定銘柄マスタを連携させ、地域が特定できれば特定銘柄フラグも自動判定できる設計が良さそう
- ただし「ブコバ地区を除く」「ガヨマウンテン地区を除く」のような**除外条件**があるため、単純な国・地域の一致だけでなく、除外ロジックも必要
- 店舗の商品名に「キリマンジャロ」「マンデリン」等の特定銘柄名が直接書かれているケースが最も多いと想定されるため、実務的には**商品名からのキーワード抽出が主軸**、産地マスタとの照合は精度検証・補完に使う、という役割分担が現実的
