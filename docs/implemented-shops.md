(実際の最新値はdata/products.jsonを参照)。「方式」が「手動」の店舗は
`scraper/manual/shops/`配下、それ以外は`scraper/scrape_*.py`で自動取得。

再生成コマンド:
```
node scripts/gen-implemented-shops.js
```

## 週次スクレイピングの所要時間(実測)

`.github/workflows/scrape-shops.yml`の`schedule`/`workflow_dispatch`(shop=all)による
全店舗実行の実測値。`scrape1`・`scrape2`のmatrix並列実行(GitHub Actions既定の並列数、
概ね20並列)により、店舗数が増えても実行時間は緩やかにしか伸びない。内容に変更が
無い店舗があっても、変更の有無はサイトへの実際のリクエスト無しには判定できないため、
スクレイピング自体の所要時間は短縮されない(短縮されるのは最後のコミット処理のみ、
aggregate_shops.py実行後の`git diff --staged --quiet || git commit`が該当、
全体に対してごく僅か)。
