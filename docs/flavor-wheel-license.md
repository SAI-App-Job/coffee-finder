# フレーバーホイール・センサリーレキシコンの利用条件(調査)

調査日: 2026-11-10。**これは公開資料の読み取りで、法的助言ではない。** 最終判断(特に商用・翻訳・構造の再現)は、必要なら弁護士か権利者に確認する。
読んだ方法は、特記がなければ「原文(HTML/PDF/条文)を取得して読んだ」。

## 1. 結論(先に)

- **SCAのホイール(Coffee Taster's Flavor Wheel)は CC BY-NC-ND 4.0。** 非営利のみ、改変(翻訳・並べ替え)した形の公開は禁止。
- **WCRのセンサリーレキシコンは CC ではない(All rights reserved)。** 「個人用に印刷・ダウンロードするのは自由」としか書いていない。転載・翻訳掲載の許諾は、確認できなかった。
- アプリの現在の「フレーバーホイール」画面は、ホイールの**用語を日本語に訳し、独自のグループに再構成**したもの。**CCのND条件に抵触する可能性が高い**(下の4)。そのため、公開停止のまま。
- 安全な道は、**公式へリンクする**(A)か、**権利者に許諾を取る**(C)こと。

## 3. 行為ごとの可否の見立て

「○」=問題が小さい / 「△」=グレー、確認が必要 / 「×」=禁止または抵触の可能性が高い。

| 行為 | SCAホイール(CC BY-NC-ND) | WCRレキシコン(All rights reserved) |
|---|---|---|
| 公式ページへのリンク、画像のURLへの誘導 | ○(複製しない) | ○ |
| 画像をそのまま転載 | **非営利なら可**(表示・リンク・ライセンス表記が必要)。広告・課金のあるアプリは×の可能性 | ×(許諾が確認できない。個人用印刷までと読める) |
| 日本語に訳して掲載 | ×(翻訳はAdapted Material。NDで共有できない) | ×(翻訳掲載の許諾が確認できない。公式の中国語訳は「情報提供のみ・販売不可」の条件つき) |
| 並べ替え・独自のカード形式にして掲載 | ×(arrangedはAdapted Material) | △(定義文を写さず、語の一覧だけなら下の行) |
| 単語・短い語句(Fruity、Floral、Jasmine…)を使う | ○に近い(単語や短い語句は、創作的な表現とは言いにくい。**私の読みで、公式の確認はない**) | 同左 |
| 階層構造(大分類→サブグループ→語)をほぼそのまま再現 | △〜×(選択・配列に創作性があれば第12条・第12条の2の保護。CCのNDも関係する) | △〜× |
| 定義文・説明文の転載や翻訳 | ×(翻訳は第27条、CCではND) | ×(許諾なし) |
| 引用(第32条): 短い一節を、解説の中で出典を明示して使う | ○(CCの条件に関わらず、引用の要件を満たせば可) | ○(同左) |
| 商品の香味メモを、大分類名(例: Fruity)で自動分類して表示 | ○(機能として語を照合するだけ。大分類名は短い語) | ○ |

引用の要件の補足: 第32条は「公正な慣行」と「目的上正当な範囲」を求める。判例上は、自分の文章が主で引用が従であること、引用部分が明確に区別されること、も要件とされる(**判決文の一次資料は未確認**)。ホイールの用語一覧をそのまま見せる画面は、引用が主になるので、引用に当たらない。

## 4. このアプリの現状への当てはめ

- 現在の `src/data/flavorWheel.js` は、**9大分類・22サブグループ・84語**を日本語に訳し、一部は独自のグループに組み替えたもの(検証担当の報告では、5件が公式の分類と食い違い)。
- 画面の「フレーバーホイール」は、これをカードで展開表示する。**「日本語訳」+「独自の再構成」**に当たるため、**SCAのホイールを改変して公開している**と評価される可能性が高い(ND)。
- アプリには広告の枠(`AdBanner`)と、プレミアムの切り替えがある。現時点では、広告・課金は使っていない(ストア掲載文も「現在、広告やアクセス解析は使っていません」)。ただし**将来、広告・課金を入れると「非営利(NC)」を満たさなくなる**。
- WCRレキシコン由来の用語は、定義文を使っていなければ、リスクは低い。ただし、**語の選択・階層が元の資料にほぼ依存**している点は残る。

## 5. 選べる道

| 案 | 内容 | 長所 | 短所 |
|---|---|---|---|
| A. リンクだけ | アプリはホイールを載せず、SCAの公式ページ(日本語版ポスターを含む)とWCRのレキシコンへ案内する。出典として明記する | 最も安全。作業が少ない | アプリ内で完結しない |
| B. 大分類名だけ使う | 商品の香味の自動分類(Fruityなど9つの大分類名)だけ残し、ホイール画面は出さない | 機能は維持できる | 分類の根拠を説明する画面がない |
| C. 許諾を取る | SCA(ホイールの権利者)とWCRに、翻訳・再構成して掲載してよいか問い合わせる。WCRの連絡先はページに info@worldcoffeeresearch.org | 許諾が出れば全面的に復活できる | 返事を待つ。商用(広告・課金)の可否も確認が必要 |
| D. 独自に作る | 公式の分類に依存せず、日本の香味表現を独自に整理する | ライセンスの制約がない | 「公式のホイール」とは言えない。元の資料に似すぎれば、結局リスクが残る |

私の推奨は **A(まず安全に)+C(許諾の問い合わせ)** です。C の問い合わせ文は、必要なら作ります。

- SCAJ(日本スペシャルティコーヒー協会)が日本語版の許諾を持っているか、SCAストアの日本語版の条件が英語版と同じか。

## 7. 検索・テイスティングノート・ログでの使用(追記: 2026-11-10)

コード(`src/data/flavorWheel.js`、`src/utils/flavor.js`、`src/components/FlavorPicker.jsx`、`FilterSheet.jsx`)を読んで整理した。

| 使い方 | 画面に出るもの | 見立て |
|---|---|---|
| 検索の絞り込み(`FilterSheet`) | 9つの大分類名(日本語)と、アプリ独自の色 | 低リスク。短い語9つで、色は独自。 |
| 商品の香味メモの自動分類(`categorizeFlavorNotes`、商品カード・詳細・好みの傾向・おすすめ) | 該当した大分類名のタグ | 低リスク。語を照合する内部処理で、画面に出るのは大分類名だけ。ただし**タグの説明文が「SCA/WCRフレーバーホイールの『◯◯』カテゴリに該当と自動分類」と書いており、実態と合わない**(下記)。 |
| テイスティングノート・ログ・登録商品・店舗ノートの入力(`FlavorPicker`) | **9大分類 → 22グループ → 84語を、日本語で展開して選べる画面** | **要注意。** 非公開にしたフレーバーホイール画面と、実質同じ「翻訳+独自の再構成」を、入力部品として出している。 |
| 記録した風味の表示(`FlavorChips`) | 利用者が選んだ語と色 | 低リスク。利用者自身のデータ。 |

### 表記と実態のずれ(出典の規則に関わる)
- `FlavorPicker` のコメントと商品タグの説明は、アプリの分類を「SCA/WCRフレーバーホイールと同じ」と述べている。しかし、検証担当の報告では、**公式の分類と食い違う箇所が5件**あり、**グループ名の一部(バニラ系、刺激的な香り、たばこ系、その他)はアプリ独自**。さらに、`FLAVOR_TERM_INDEX` には、SCA/WCRにない語(bergamot、berry、ベリー、キャラメルなど)が入っている。
- 「公式と同じ」「SCA/WCRのカテゴリに自動分類」と読める文言は、出典の規則上、確認できない主張になる。**文言を実態(アプリ独自の分類)に直す**必要がある。

## 8. 対応(2026-11-10、ユーザーの決定: 案2)
- 豆知識の「フレーバーホイール」のボタンとページを非表示にした(コードも削除。`FlavorWheelView.jsx`、`src/data/flavorWheel.js`)。
- 風味の入力・検索の絞り込み・自動分類は、**ホイールに依存しないアプリ独自の語彙**(`src/data/flavorVocabulary.json`)に作り替えた。詳細と更新手順は `docs/flavor-vocabulary.md`。
- 「SCA/WCRフレーバーホイールに自動分類」「ホイールにもとづく」の表記は、「アプリ独自の分類」に直した(画面・ストア掲載文)。
- 旧い語彙で記録された語は、`legacy` に残し、そのまま表示できる。
- 豆知識「フレーバーホイールの生みの親」(出典確認済み)は、ホイールの掲載ではなく歴史の記述なので、残している。
