## 今回の教訓と手順
- 一次資料は、**各国の規格機関の目録**(例: メキシコのPLATIICA)にあることが多い。ただし、**有償の規格**(ISOに準ずる各国規格)は、無償では取得できない。
- 有償の規格を購入するのは、利用者の判断(支出を伴う)。購入した場合は、`python scripts/archive_source.py import <資料ID> <ファイル> <URL> --note 購入` で保存する。
- 取得に失敗した資料は、`docs/source-archive-failures.json`(取得コマンドが記録する)にも残る。

## 追記(2026-11-10・夜): ルワンダ・パナマ・ジャマイカの再調査
- **ジャマイカ**: BSJ(ジャマイカ規格局)の**草案 DJS 61:2024**(公開コメント用。JS 61:2016の改訂案)を、Waybackの保存版(2025-08-07)から取得した(`bsj-djs-61-2023-public-enquiry`。BSJの現行サイトでは、元のURLが404)。**等級ごとの数値の表はない**。書いてあるのは、生豆の水分10〜12.5%、ふるい分け試験(17・16・15・10番)の報告、規定より小さい豆は5%まで(ピーベリー10%)、上質の輸出等級は軽い欠点豆3%まで、ブレンドの名乗りの条件(30%)など。これらを `gradeSystem` に載せた(草案であることと、成立版は未取得であることを明記)。旧記述(No.1〜3・ピーベリー・トリアージ)は、一次資料で確認できないため削除。ブルーマウンテンの等級の数値は、成立版のJS 61:2024(有償)か、JACRAの規則にあると思われるが、無償では取得できない。BSJの草案は、WTOにも通報されている(G/TBT/N/JAM/122、2024-01-15)が、WTOの添付ファイルのURLは特定できなかった。
- **ルワンダ**: RSB(ルワンダ規格局)の強制規格の指示書(2015年、`rsb-ministerial-instr-23-2015-compulsory-stds`)には、焙煎豆RS 33・インスタントRS 34があるだけで、**緑豆の規格RS 97は載っていない**(前に取得した冊子には、RS 97の題名のみ)。RSBの専門委員会(RSB/TC 035、コーヒー)のページには、範囲と委員の名簿だけ。NAEBの記事(`naeb-inside-warehouses`)は、機械と手選別で選別すると書くだけで、等級の定義はない。ルワンダは東アフリカ共同体の加盟国で、地域規格EAS 130(取得済み)があるが、ルワンダがこれを緑豆の等級に採用しているかは、確認できていない。
- **パナマ**: 商工省(MICI)の技術規格の目録2022(`mici-pa-catalogo-normas-tecnicas-2022`)に、**コーヒーの規格は載っていない**(「café」で該当なし)。検索でも、パナマの緑豆の等級・品質の規則は見つからなかった。公的な等級の制度は、見つからないままとして扱う。
- **Wayback**: 断続的に停止する(今日は、停止と復旧を繰り返した)。取得できない時は、時間を空けて再試行する。
- 取得したが、無関係だった資料(砂糖・飲料の規格案)は、保存から外した。
